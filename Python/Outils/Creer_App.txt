======================================================
1 ère étape : Installation de python et des librairies
======================================================

Liens d'installation :
->    https://www.python.org/downloads/

Dans le cmd :
->    pip install pywin32 
->    pip install pyinstaller


====================================
2 ème étape : Commandes dans le cmd 
====================================

Définir le chemin d'accès :
->    cd copy_of_path_folder_for_pythonfile

Générer l'application à partir du script Python :
->    pyinstaller --onefile your_script.py


#Possibilité d'ajouter des fonctionnalités à votre Application :

--noconsole : Ouvre l'application sans la console en arrière plan (écran noir). Utile lors d'une app avec interface (Tkinter, Pygame, etc...)
->    pyinstaller --onefile --noconsole your_script.py

-i mon_icone.ico : Défini l'icone par défaut de mon application
->    pyinstaller --onefile -i mon_icone.ico your_script.py
